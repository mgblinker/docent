Tagged `[Trait("Category","Postgres")]`. CI runs everything; locally, `docker context use colima` first (or `--filter "Category!=Postgres"` to skip). - `ClientService.GetClientList<T>()` and `GetClientRelativesQueryHandler` call `GenericRepository.GetListAsync<T>(...)` without a projection. `QueryExecutionService.ExecuteQueryForType` then throws `"Projection is required for mapping X to Y"` because no auto-discovery picks it up. Affects every CareManagement list/details endpoint — production code path, not test-only. Severity: high (handlers are unreachable; tests for those endpoints can't be added until fixed). Fix probably needs a projection parameter wired from `ClientMappings.ToClientDto` into the service call.
- Test JWT generated by `TestWebApplicationFactory.GenerateJwtToken` has no associated CoreData Contact, so any handler that calls `GetCurrentUserContactQuery` returns Fail → 404. Workaround for now: write tests for that failure-path; longer term, seed a contact for the test user. Severity: medium.
